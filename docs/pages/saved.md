## 뷰 모드

### 1. 단어별 그룹 (기본)

저장한 쇼츠를 단어별로 묶어서 표시

```
serendipity (3개 쇼츠 저장)
├── 쇼츠 1: 카페에서 우연히...
├── 쇼츠 2: 잃어버린 지갑...
└── 쇼츠 3: 우연히 들어간...
```

### 2. 타임라인 (옵션)

저장한 순서대로 표시

## 인터랙션

| 동작 | 결과 |
|------|------|
| 카드 탭 | 해당 단어로 이동 (홈 피드) |
| 좌측 스와이프 | 삭제 버튼 노출 |
| 편집 모드 | 다중 선택 삭제 |
| 길게 누르기 | 상세 미리보기 (옵션) |
