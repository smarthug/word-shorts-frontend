## 설정 항목

### 학습 설정

| 항목 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| 내 레벨 | select | 중급 | 추천 단어 필터링 |
| 자동 발음 | toggle | ON | 단어 보일 때 자동 발음 |
| 반복 재생 | toggle | OFF | 영상 반복 재생 |

### 화면 설정

| 항목 | 타입 | 기본값 | 설명 |
|------|------|--------|------|
| 다크 모드 | toggle | ON | 테마 설정 |
| 자동 전체화면 | toggle | OFF | 홈에서 전체화면 |

### 데이터

| 항목 | 동작 |
|------|------|
| 학습 통계 | 학습량, 저장 단어 수 등 |
| 저장 목록 초기화 | localStorage 클리어 (확인 필요) |
| 데이터 내보내기 | JSON 다운로드 |

## 컴포넌트 구조

```
Settings
├── Header
├── SettingsSection (학습)
│   ├── SelectItem (레벨)
│   ├── ToggleItem (자동 발음)
│   └── ToggleItem (반복 재생)
├── SettingsSection (화면)
│   ├── ToggleItem (다크 모드)
│   └── ToggleItem (전체화면)
├── SettingsSection (데이터)
│   ├── LinkItem (통계)
│   ├── ActionItem (초기화)
│   └── ActionItem (내보내기)
├── SettingsSection (정보)
│   ├── LinkItem (이용약관)

```
